# HAZEL 카페24 의류 스킨

미니멀 데일리웨어 쇼핑몰용 카페24 스킨입니다. 아이보리·차콜·카멜 톤, 넓은 여백, 가운데 로고, 3:4 상품 사진.

- 고객에게 보여 줄 데모: https://nanaweb-nine.vercel.app/sites/hazel-closet (샘플 상품, 장바구니까지 동작)
- 이 폴더: 실제 카페24 쇼핑몰에 옮기는 파일

## 파일

| 파일 | 넣는 곳 |
|---|---|
| `css/hazel.css` | 스마트디자인 편집 → 파일 업로드 → `/web/upload/hazel/hazel.css` |
| `images/*.webp` | 파일 업로드 → `/web/upload/hazel/` (메인 비주얼·룩북·쇼룸 사진. 상품 사진은 상품 등록 때 넣습니다) |
| `layout_head.html` | `layout/basic/layout.html` 의 `</head>` 바로 위 (+ 상단 띠는 `<body>` 바로 아래) |
| `main_index.html` | `index.html` 본문 교체 (메인 비주얼, 혜택 띠, NEW/BEST 진열, 룩북, 쇼룸) |
| `products-sample.csv` | 샘플 상품 8개 (관리자 → 상품 → 상품 엑셀 등록 참고용 목록) |

## 적용 순서 (약 30분)

1. **스킨 복사**: 관리자 → 디자인(PC/모바일) → 디자인 보관함에서 기본 스킨(심플 등)을 **복사**해 작업용 스킨을 만듭니다. 원본은 건드리지 않습니다.
2. **파일 업로드**: 복사한 스킨의 스마트디자인 편집 → 파일 업로드로 `/web/upload/hazel/` 폴더를 만들고 `hazel.css`와 `images/` 안의 사진을 올립니다.
3. **레이아웃**: `layout/basic/layout.html` 을 열어 `layout_head.html` 내용을 붙여넣습니다.
4. **메인**: `index.html` 을 열어 맨 위 레이아웃 선언 줄은 두고, 본문을 `main_index.html` 로 교체합니다.
   - 버튼 링크의 카테고리 번호(`cate_no=24` 등)를 실제 쇼핑몰 번호로 바꿉니다.
5. **상품 진열**: 관리자 → 상품 → 메인 진열 관리에서 1번(NEW)·2번(BEST)에 상품을 넣습니다.
6. **미리보기**로 PC·모바일을 확인한 뒤 **대표 디자인으로 설정**합니다.

## 확인할 점

- 기본 스킨 종류에 따라 헤더·푸터의 클래스 이름이 조금 다를 수 있습니다. 로고가 두 번 보이거나 메뉴 색이 안 바뀌면 `hazel.css` 2번 영역의 선택자를 스킨에 맞게 고칩니다.
- 상품 모듈(`product_listmain_N`, `{$image_medium}`, `{$product_name}`, `{$disp_product_price}`, `{$param}`)은 실제 운영 중인 명당연구소 카페24 스킨에서 검증된 문법과 같습니다. 상품이 비어 보이면 메인 진열 번호(1·2)에 상품이 들어 있는지 먼저 확인하세요.
- `main_index.html` 맨 아래에 카페24 사업자 정보 푸터(`Layout_footer`) 예시가 주석으로 들어 있습니다.
- 로고는 글자(HAZEL)로 표시합니다. 이미지 로고를 쓰려면 `hazel.css` 의 `.xans-layout-logotop` 두 줄을 지우면 기본 로고 이미지가 보입니다.
- 샘플 사진은 AI로 만든 가상 이미지입니다. 실제 판매 시에는 직접 촬영한 상품 사진으로 바꿔 주세요.
