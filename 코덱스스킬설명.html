Codex Skills Guide

코덱스에서 보이는 스킬/워크플로 설명

채팅창에서 / 또는 스킬 목록을 볼 때 나오는 기능들을 초보자 기준으로 정리한 문서입니다. 각 스킬은 “언제 쓰는지”, “무슨 일을 하는지”, “주의할 점” 중심으로 설명했습니다.

기본스킬 생성/설치/문서/이미지
OMX계획·분석·검증·팀 작업
플러그인브라우저·컴퓨터·문서·시트·발표
주의배포/삭제/외부 권한은 신중히

먼저 알아둘 점

스킬은 코덱스가 특정 작업을 더 안정적으로 수행하기 위한 “작업 방식 묶음”입니다.

단순 질문은 그냥 물어보면 되고, 복잡한 작업은 “분석해줘”, “계획 세워줘”, “검증해줘”, “브라우저로 확인해줘”처럼 목적을 말하면 알맞은 스킬이 적용됩니다.

자주 쓰는 핵심 스킬

실제 프로젝트 수정, 오류 해결, 화면 확인 때 가장 자주 쓰는 기능입니다.

analyze OMX

코드를 수정하기 전에 원인과 구조를 읽기 전용으로 분석합니다. “왜 안 돼?”, “원인 찾아줘”, “어디가 문제야?” 같은 요청에 적합합니다.

plan / ralplan OMX

수정 전에 작업 순서, 위험 지점, 테스트 방법을 정리합니다. 큰 기능 추가나 여러 파일 변경 전에 좋습니다.

ralph OMX

목표가 끝날 때까지 구현→검증→수정 루프를 반복하는 지속 작업 모드입니다. 다만 프로젝트 환경에 따라 계획 문서가 먼저 필요할 수 있습니다.

team / swarm OMX

여러 에이전트를 나눠서 작업시키는 팀 작업 모드입니다. 큰 기능, 디자인+구현+검증을 병렬로 처리할 때 씁니다.

ultraqa OMX

공격적으로 테스트 케이스를 만들고, 깨질 만한 시나리오를 확인하는 QA 스킬입니다. 배포 전 검증에 유용합니다.

code-review OMX

수정된 코드가 안전한지, 버그 가능성은 없는지, 유지보수하기 쉬운지 리뷰합니다.

브라우저/화면 확인 스킬

웹사이트 화면, 로컬 서버, 콘솔 오류, 클릭 동작 등을 확인할 때 사용합니다.

browser:control-in-app-browser Browser

코덱스 안의 브라우저로 localhost, 배포 사이트, 현재 페이지를 열고 클릭/입력/스크린샷/콘솔 확인을 합니다.

  • 프론트엔드 수정 후 실제 화면 검증에 필수입니다.

visual-ralph OMX

목표 디자인이나 스크린샷을 기준으로 화면이 맞을 때까지 수정과 시각 검증을 반복합니다.

stitch-design Design

Stitch 디자인 작업, 화면 생성, 디자인 시스템 정리를 돕는 스킬입니다.

stitch-loop Design

Stitch로 웹사이트를 반복 생성·수정하는 루프형 작업 방식입니다.

이미지/문서/자료 생성 스킬

코드가 아니라 이미지, 문서, 발표자료, 스프레드시트 같은 산출물을 만들 때 씁니다.

imagegen System

새 이미지 생성, 기존 이미지 편집, 썸네일/비주얼 에셋 제작에 사용합니다. HTML/CSS로 만들 수 있는 벡터나 UI는 코드로 만드는 편이 낫습니다.

documents Documents

Word 문서, .docx 파일을 만들거나 수정하고 렌더링해서 레이아웃까지 확인합니다.

presentations Presentations

PowerPoint/PPTX 발표자료를 만들고 시각적으로 검증합니다.

spreadsheets Spreadsheets

엑셀, CSV, 표, 수식, 차트, 데이터 분석용 파일을 만들거나 수정합니다.

조사/문서 기반 답변 스킬

외부 공식 문서, 최신 API, 라이브러리 사용법이 필요할 때 사용합니다.

openai-docs System

OpenAI API, ChatGPT, Codex, 모델 선택, 프롬프트 업그레이드 같은 질문에 공식 문서 기준으로 답합니다.

best-practice-research OMX

공식 문서와 신뢰 가능한 근거를 우선으로 모아 모범 사례를 정리합니다.

autoresearch / autoresearch-goal OMX

조사 목표를 세우고 검증자 관점으로 반복 조사하는 스킬입니다. 시간이 걸리지만 근거 중심 결과에 좋습니다.

ask OMX

Claude/Gemini 같은 외부 조언자 CLI에 질문하고, 재사용 가능한 답변 아티팩트를 남기는 기능입니다.

프로젝트 관리/상태 관리 스킬

작업 기록, 설치 상태, 진행 상황, 워크플로 제어에 관련된 기능입니다.

cancel Control

진행 중인 OMX 모드나 워크플로를 취소합니다. 작업 중단 요청이 있을 때 사용합니다.

doctor OMX

oh-my-codex 설치 상태와 문제를 진단하고 고칩니다.

hud OMX

OMX 상태 표시줄/HUD를 보여주거나 설정합니다.

wiki OMX

프로젝트용 지속 문서 위키를 만들고 검색/기록합니다. 다음 AI가 이어받기 좋게 합니다.

pipeline OMX

여러 작업 단계를 순서대로 실행하는 파이프라인을 구성합니다.

ultragoal / performance-goal OMX

큰 목표를 여러 하위 목표로 나누거나 성능 최적화 목표를 장기적으로 관리합니다.

스킬/플러그인 만들기와 설치

코덱스 자체 기능을 확장할 때 사용하는 관리용 스킬입니다.

skill-creator System

새 스킬을 만들거나 기존 스킬을 개선할 때 안내합니다.

skill-installer System

큐레이션된 스킬이나 GitHub 저장소의 스킬을 설치합니다.

plugin-creator System

Codex 플러그인 디렉터리와 manifest를 스캐폴딩합니다.

skill OMX

로컬 스킬을 검색, 추가, 제거, 편집, 설정하는 관리 기능입니다.

어떻게 말하면 좋을까?

분석 요청

“이 오류 원인 분석해줘. 수정하지 말고 먼저 어디가 문제인지 알려줘.”

수정 요청

“기존 잘 되는 코드는 건드리지 말고 최소 수정으로 고쳐줘. 빌드까지 확인해줘.”

화면 검증

“브라우저로 열어서 PC/모바일 화면 깨짐과 콘솔 에러 확인해줘.”

배포 확인

“배포 후 실제 주소에서 대표 경로 2~3개 열어서 확인해줘.”
