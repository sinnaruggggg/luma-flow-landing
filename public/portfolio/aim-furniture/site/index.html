메인 갤러리

원목의 분위기를 담은 가구 이미지와 공간 배치를 한 화면에서 보여주는 쇼룸.

아틀리에 모듀는 단순한 가구 목록이 아니라, 실제 홍보 페이지처럼 보이는 비주얼 중심 쇼룸으로 구성했습니다. 메인은 갤러리로 두고, 배치 기능과 마감 비교는 각각의 전용 페이지로 분리했습니다.
