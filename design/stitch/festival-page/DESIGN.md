# Design System: NOISE WAVE
**Site ID:** festival-page

## 1. Visual Theme & Atmosphere
- 핵심 톤: 포스터형 이벤트 사이트
- 첫 화면 문법: 라인업 포스터와 티켓 CTA가 즉시 보이는 몰입형 히어로
- 배경 규칙: 네온 포스터 비주얼과 스크롤 반응형 광선
- 인터랙션 톤: 라인업, 일정, 티켓 카드가 무대 레이어처럼 차례로 등장
- 시각 성격: 다크 배경, 네온 라인, 기술적 반응감을 가진 레트로 퓨처 화면

## 2. Color Palette & Roles
- Primary Action (#39d5ff): 핵심 CTA와 활성 상태에 사용한다.
- Accent Soft (#ff6fe4): 보조 태그, 하이라이트 패널, 그래프 포인트에 사용한다.
- Surface (#0e1b33): 카드, 패널, 정보 블록의 기본 바탕에 사용한다.
- Background (#07101d): 페이지 전체 무드와 깊이를 결정하는 바탕에 사용한다.
- Text (#ecfbff) / Muted (rgba(203, 241, 255, 0.76)): 제목과 짧은 설명의 위계를 분리한다.

## 3. Typography Rules
- 대시보드형 헤드라인과 기술 라벨을 분리해 사용한다.
- 본문은 길게 쓰지 않고, 화면이 기능을 설명하게 한다.
- 영어는 브랜드명, 짧은 라벨, 스타일 포인트에만 제한적으로 사용한다.

## 4. Component Stylings
- 얇은 라인, 글로우, 패널 스택으로 깊이를 만든다.
- 공통화는 버튼, 배지, 입력, 기본 카드 정도까지만 허용한다.
- 리스트와 표는 실제 운영 사이트처럼 바로 행동으로 이어지게 구성한다.

## 5. Home Screen Rules
- 다른 사이트와 같은 첫 화면 구문으로 보이면 안 된다.
- 데스크톱은 큰 비주얼 또는 강한 정보 구조가 먼저 보이게 만든다.
- 모바일은 축소판이 아니라 전용 모바일 레이아웃으로 다시 설계한다.
- 이미지형 사이트는 큰 대표컷과 떠오르는 레이어를 사용한다.
- 비이미지형 사이트는 포인터/스크롤 반응형 메시 또는 오로라 배경을 사용한다.

## 6. Prohibited Patterns
- 공통 히어로 템플릿 금지
- 공통 섹션 조립기 금지
- 같은 이미지 박스 + 설명 박스 + CTA 반복 금지

## 7. Route Targets
- 홈 (`home`): 실제 운영 중인 서비스 홈처럼 보이게 만들고, 상단 메뉴는 고정한다. 첫 화면 문법이 이 사이트만의 구조로 보이게 만들고, 공통 히어로 템플릿이나 반복 섹션 조립기처럼 보이면 안 된다.
- 라인업 (`lineup`): 출연진/라인업 페이지다. 아티스트 카드, 날짜, 장르, 대표 비주얼이 핵심이다.
- 시간표 (`schedule`): 타임테이블 페이지다. 시간표, 스테이지, 동선, 구역 정보를 명확히 정리한다.
- 티켓 (`tickets`): 티켓 구매 페이지다. 좌석/티켓 종류, 가격, 혜택, 구매 버튼이 핵심이다.
- 가이드 (`guide`): 안내 페이지다. 방문 전 알아야 할 내용, 운영 정보, 규정, 준비물, FAQ를 정리한다.
