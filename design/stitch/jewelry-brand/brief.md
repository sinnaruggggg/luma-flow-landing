# LUNE FORM

- 사이트 ID: `jewelry-brand`
- 업종: 주얼리 브랜드
- 요약: 컬렉션 · 맞춤 상담 · 구매
- 디자인 계열: 컬렉션형 럭셔리 사이트
- 히어로: 주얼리 클로즈업 컷과 컬렉션 CTA 중심의 히어로
- 배경: 디테일 매크로 사진과 금속성 반짝임
- 모션: 컬렉션 블록과 상담 카드가 미세하게 떠오름

## 금지 패턴
- 공통 히어로 템플릿 금지
- 공통 섹션 조립기 금지
- 같은 이미지 박스 + 설명 박스 + CTA 반복 금지

## 페이지 구조
- 홈 (`home`): 실제 운영 중인 서비스 홈처럼 보이게 만들고, 상단 메뉴는 고정한다. 첫 화면 문법이 이 사이트만의 구조로 보이게 만들고, 공통 히어로 템플릿이나 반복 섹션 조립기처럼 보이면 안 된다.
- 컬렉션 (`collection`): 탐색/목록 페이지다. 필터, 카테고리, 리스트, 빠른 진입 구조를 직관적으로 보여준다.
- 맞춤 (`bespoke`): 상세 설명 페이지다. 비교, 디테일, 기능, 컬러, 노트, 배치처럼 깊이 있는 정보를 중심으로 구성한다.
- 상담 (`consult`): 전환 페이지다. 구매, 장바구니, 세트 선택, 상담 신청, 선물 구성처럼 바로 결정을 내리게 만든다.
- 브랜드 (`brand`): 브랜드 신뢰 형성 페이지다. 브랜드 스토리, 가치, 제작 배경, 지원 정보를 짧고 세련되게 보여준다.
