# Design System: TABLE WARM
**Site ID:** local-cafe

## 1. Visual Theme & Atmosphere
- 핵심 톤: 로컬 스몰비즈니스
- 첫 화면 문법: 매장 사진과 오늘 메뉴가 같이 보이는 따뜻한 홈
- 배경 규칙: 대형 매장 사진과 낮은 강도의 패럴랙스
- 인터랙션 톤: 메뉴 카드와 예약 박스가 아래에서 천천히 떠오름
- 시각 성격: 따뜻한 소규모 브랜드, 부드러운 색감, 생활감 있는 화면

## 2. Color Palette & Roles
- Primary Action (#5d3b24): 핵심 CTA와 활성 상태에 사용한다.
- Accent Soft (#e8c498): 보조 태그, 하이라이트 패널, 그래프 포인트에 사용한다.
- Surface (#fff8ef): 카드, 패널, 정보 블록의 기본 바탕에 사용한다.
- Background (#f4ead9): 페이지 전체 무드와 깊이를 결정하는 바탕에 사용한다.
- Text (#2b221a) / Muted (#6a5c4f): 제목과 짧은 설명의 위계를 분리한다.

## 3. Typography Rules
- 친근한 제목과 짧은 안내 문구를 사용한다.
- 본문은 길게 쓰지 않고, 화면이 기능을 설명하게 한다.
- 영어는 브랜드명, 짧은 라벨, 스타일 포인트에만 제한적으로 사용한다.

## 4. Component Stylings
- 예약/메뉴 카드에는 손맛 있는 선과 따뜻한 배경을 준다.
- 공통화는 버튼, 배지, 입력, 기본 카드 정도까지만 허용한다.
- 리스트와 표는 실제 운영 사이트처럼 바로 행동으로 이어지게 구성한다.

## 5. Home Screen Rules
- 다른 사이트와 같은 첫 화면 구문으로 보이면 안 된다.
- 데스크톱은 큰 비주얼 또는 강한 정보 구조가 먼저 보이게 만든다.
- 모바일은 축소판이 아니라 전용 모바일 레이아웃으로 다시 설계한다.
- 이미지형 사이트는 큰 대표컷과 떠오르는 레이어를 사용한다.
- 비이미지형 사이트는 포인터/스크롤 반응형 메시 또는 오로라 배경을 사용한다.

## 6. Prohibited Patterns
- 공통 히어로 템플릿 금지
- 공통 섹션 조립기 금지
- 같은 이미지 박스 + 설명 박스 + CTA 반복 금지

## 7. Route Targets
- 홈 (`home`): 실제 운영 중인 서비스 홈처럼 보이게 만들고, 상단 메뉴는 고정한다. 첫 화면 문법이 이 사이트만의 구조로 보이게 만들고, 공통 히어로 템플릿이나 반복 섹션 조립기처럼 보이면 안 된다.
- 메뉴 (`menu`): 탐색/목록 페이지다. 필터, 카테고리, 리스트, 빠른 진입 구조를 직관적으로 보여준다.
- 매장 (`visit`): 상세 설명 페이지다. 비교, 디테일, 기능, 컬러, 노트, 배치처럼 깊이 있는 정보를 중심으로 구성한다.
- 예약 (`reserve`): 예약/신청 페이지다. 일정, 슬롯, 상담 또는 시승/예약 폼이 핵심이다.
- 안내 (`info`): 안내 페이지다. 방문 전 알아야 할 내용, 운영 정보, 규정, 준비물, FAQ를 정리한다.
