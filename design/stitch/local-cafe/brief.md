# TABLE WARM

- 사이트 ID: `local-cafe`
- 업종: 로컬 카페
- 요약: 메뉴 · 좌석 · 예약
- 디자인 계열: 로컬 스몰비즈니스
- 히어로: 매장 사진과 오늘 메뉴가 같이 보이는 따뜻한 홈
- 배경: 대형 매장 사진과 낮은 강도의 패럴랙스
- 모션: 메뉴 카드와 예약 박스가 아래에서 천천히 떠오름

## 금지 패턴
- 공통 히어로 템플릿 금지
- 공통 섹션 조립기 금지
- 같은 이미지 박스 + 설명 박스 + CTA 반복 금지

## 페이지 구조
- 홈 (`home`): 실제 운영 중인 서비스 홈처럼 보이게 만들고, 상단 메뉴는 고정한다. 첫 화면 문법이 이 사이트만의 구조로 보이게 만들고, 공통 히어로 템플릿이나 반복 섹션 조립기처럼 보이면 안 된다.
- 메뉴 (`menu`): 탐색/목록 페이지다. 필터, 카테고리, 리스트, 빠른 진입 구조를 직관적으로 보여준다.
- 매장 (`visit`): 상세 설명 페이지다. 비교, 디테일, 기능, 컬러, 노트, 배치처럼 깊이 있는 정보를 중심으로 구성한다.
- 예약 (`reserve`): 예약/신청 페이지다. 일정, 슬롯, 상담 또는 시승/예약 폼이 핵심이다.
- 안내 (`info`): 안내 페이지다. 방문 전 알아야 할 내용, 운영 정보, 규정, 준비물, FAQ를 정리한다.
