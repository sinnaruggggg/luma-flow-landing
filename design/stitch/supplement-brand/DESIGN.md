# Design System: PUNCH FUEL
**Site ID:** supplement-brand

## 1. Visual Theme & Atmosphere
- 핵심 톤: DTC 퍼포먼스 브랜드
- 첫 화면 문법: 제품과 루틴 구성이 동시에 보이는 기능형 히어로
- 배경 규칙: 깨끗한 제품 배경과 미세한 빛 번짐
- 인터랙션 톤: 성분 카드와 구독 박스가 레이어처럼 밀려 올라옴
- 시각 성격: 강한 대비, 두꺼운 외곽선, 원색 포인트가 바로 읽히는 네오 브루탈 상업 화면

## 2. Color Palette & Roles
- Primary Action (#ff6b6b): 핵심 CTA와 활성 상태에 사용한다.
- Accent Soft (#7dd3fc): 보조 태그, 하이라이트 패널, 그래프 포인트에 사용한다.
- Surface (#fffdf4): 카드, 패널, 정보 블록의 기본 바탕에 사용한다.
- Background (#f7e45d): 페이지 전체 무드와 깊이를 결정하는 바탕에 사용한다.
- Text (#121212) / Muted (#5d5649): 제목과 짧은 설명의 위계를 분리한다.

## 3. Typography Rules
- 헤드라인은 크게 밀어붙이고, 라벨은 짧고 빠르게 읽히게 만든다.
- 본문은 길게 쓰지 않고, 화면이 기능을 설명하게 한다.
- 영어는 브랜드명, 짧은 라벨, 스타일 포인트에만 제한적으로 사용한다.

## 4. Component Stylings
- 버튼과 정보 카드에는 명확한 외곽선과 물리적인 그림자를 준다.
- 공통화는 버튼, 배지, 입력, 기본 카드 정도까지만 허용한다.
- 리스트와 표는 실제 운영 사이트처럼 바로 행동으로 이어지게 구성한다.

## 5. Home Screen Rules
- 다른 사이트와 같은 첫 화면 구문으로 보이면 안 된다.
- 데스크톱은 큰 비주얼 또는 강한 정보 구조가 먼저 보이게 만든다.
- 모바일은 축소판이 아니라 전용 모바일 레이아웃으로 다시 설계한다.
- 이미지형 사이트는 큰 대표컷과 떠오르는 레이어를 사용한다.
- 비이미지형 사이트는 포인터/스크롤 반응형 메시 또는 오로라 배경을 사용한다.

## 6. Prohibited Patterns
- 공통 히어로 템플릿 금지
- 공통 섹션 조립기 금지
- 같은 이미지 박스 + 설명 박스 + CTA 반복 금지

## 7. Route Targets
- 홈 (`home`): 실제 운영 중인 서비스 홈처럼 보이게 만들고, 상단 메뉴는 고정한다. 첫 화면 문법이 이 사이트만의 구조로 보이게 만들고, 공통 히어로 템플릿이나 반복 섹션 조립기처럼 보이면 안 된다.
- 루틴 (`routine`): 탐색/목록 페이지다. 필터, 카테고리, 리스트, 빠른 진입 구조를 직관적으로 보여준다.
- 비교 (`compare`): 상세 설명 페이지다. 비교, 디테일, 기능, 컬러, 노트, 배치처럼 깊이 있는 정보를 중심으로 구성한다.
- 구독 (`subscribe`): 전환 페이지다. 구매, 장바구니, 세트 선택, 상담 신청, 선물 구성처럼 바로 결정을 내리게 만든다.
- 브랜드 (`brand`): 브랜드 신뢰 형성 페이지다. 브랜드 스토리, 가치, 제작 배경, 지원 정보를 짧고 세련되게 보여준다.
