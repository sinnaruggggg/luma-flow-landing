# Design System: BOP BOP
**Site ID:** youth-fashion

## 1. Identity
- Industry: Youth Fashion
- Summary: A youth fashion site built as a lookbook rail with strong image sequencing and fast shop entry.
- Home grammar: Lookbook rail
- Mobile rule: Transform the lookbook into swipeable outfit stacks with a direct shop CTA on each block.

## 2. Visual Direction
- Family: Lookbook commerce
- First screen: Lookbook-led hero where images and shop CTAs live in the same visual rail.
- Background: Campaign imagery, bright typography, and playful layers rather than minimalist white space.
- Motion: Looks and tags glide like a fast-moving editorial rail.
- Atmosphere: Bright, type-forward, youthful, and image-led.

## 3. Palette
- Background: #fff2a9
- Surface: #fff8d3
- Panel: rgba(255, 248, 211, 0.84)
- Text: #121212
- Muted: #4f4b43
- Accent: #0f3bd9
- Accent soft: #ff79b0

## 4. Typography
- Let display type be visible and rhythmic.
- Keep copy short and functional.
- Use Korean as the default content language.

## 5. Components
- Looks and buy prompts should move like editorial stickers.
- Shared primitives are limited to buttons, badges, inputs, and simple cards.
- The first screen grammar must be unique to this site.

## 6. Prohibited Patterns
- No shared hero template.
- No shared section assembler.
- No repetitive image box + text box + CTA blocks.

## 7. Route Targets
- Home (home): This is the operating homepage. Build a complete landing surface, not a cover page.
- Looks (looks): Use a browse or catalog structure with filtering, category anchors, and fast exploration.
- Shop (shop): Lead with product, room, program, or service depth. Make the decision points obvious.
- Cart (cart): Show an intentional conversion flow with options, quantity, summary, and next action.
- Brand (brand): Present the brand world, trust layer, and operating context rather than generic about text.
