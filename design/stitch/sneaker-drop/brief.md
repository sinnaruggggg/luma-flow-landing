# RIFT/01

- 사이트 ID: `sneaker-drop`
- 업종: 스니커즈 드롭 스토어
- 요약: 오늘 드롭 · AI 사이즈 · 장바구니
- 디자인 계열: 스트리트 드롭 커머스
- 히어로: 대형 제품 컷과 카운트다운이 먼저 보이는 하이컨트라스트 히어로
- 배경: 풀블리드 캠페인 이미지와 원색 포인트 그래픽
- 모션: 드롭 카드와 출시 시간 배지가 아래에서 떠오르듯 겹쳐 등장

## 금지 패턴
- 공통 히어로 템플릿 금지
- 공통 섹션 조립기 금지
- 같은 이미지 박스 + 설명 박스 + CTA 반복 금지

## 페이지 구조
- 홈 (`home`): 실제 운영 중인 서비스 홈처럼 보이게 만들고, 상단 메뉴는 고정한다. 첫 화면 문법이 이 사이트만의 구조로 보이게 만들고, 공통 히어로 템플릿이나 반복 섹션 조립기처럼 보이면 안 된다.
- 드롭 (`drops`): 탐색/목록 페이지다. 필터, 카테고리, 리스트, 빠른 진입 구조를 직관적으로 보여준다.
- 스타일 (`styles`): 상세 설명 페이지다. 비교, 디테일, 기능, 컬러, 노트, 배치처럼 깊이 있는 정보를 중심으로 구성한다.
- 장바구니 (`cart`): 전환 페이지다. 구매, 장바구니, 세트 선택, 상담 신청, 선물 구성처럼 바로 결정을 내리게 만든다.
- 브랜드 (`brand`): 브랜드 신뢰 형성 페이지다. 브랜드 스토리, 가치, 제작 배경, 지원 정보를 짧고 세련되게 보여준다.
