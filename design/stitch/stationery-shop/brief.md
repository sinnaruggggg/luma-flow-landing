# CUT & NOTE

- 사이트 ID: `stationery-shop`
- 업종: 문구 스토어
- 요약: 키트 빌더 · 컬러 조합 · 장바구니
- 디자인 계열: 콜라주 문구 커머스
- 히어로: 키트 구성과 종이 레이어가 먼저 보이는 홈
- 배경: 질감 배경과 작은 물리 반응형 오브젝트
- 모션: 오려 붙인 카드가 가볍게 겹쳐 올라옴

## 금지 패턴
- 공통 히어로 템플릿 금지
- 공통 섹션 조립기 금지
- 같은 이미지 박스 + 설명 박스 + CTA 반복 금지

## 페이지 구조
- 홈 (`home`): 실제 운영 중인 서비스 홈처럼 보이게 만들고, 상단 메뉴는 고정한다. 첫 화면 문법이 이 사이트만의 구조로 보이게 만들고, 공통 히어로 템플릿이나 반복 섹션 조립기처럼 보이면 안 된다.
- 키트 (`kits`): 탐색/목록 페이지다. 필터, 카테고리, 리스트, 빠른 진입 구조를 직관적으로 보여준다.
- 컬러 (`colors`): 상세 설명 페이지다. 비교, 디테일, 기능, 컬러, 노트, 배치처럼 깊이 있는 정보를 중심으로 구성한다.
- 바스켓 (`basket`): 전환 페이지다. 구매, 장바구니, 세트 선택, 상담 신청, 선물 구성처럼 바로 결정을 내리게 만든다.
- 브랜드 (`brand`): 브랜드 신뢰 형성 페이지다. 브랜드 스토리, 가치, 제작 배경, 지원 정보를 짧고 세련되게 보여준다.
