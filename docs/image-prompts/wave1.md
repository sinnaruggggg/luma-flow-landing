# 1차 시안 이미지 — GPT 복붙용 프롬프트

## 사용 방법
1. 아래 **사이트별 코드 블록 하나를 통째로 복사**해서 GPT(이미지 생성)에 붙여넣습니다.
2. GPT가 이미지를 하나씩 만들면, 각 이미지를 **적힌 파일명 그대로** 저장합니다.
3. 저장 폴더: `D:\www\mypages\public\sites\<사이트 id>\` (폴더가 없으면 만드세요)
4. 확장자는 GPT가 주는 그대로(.png) 저장해도 됩니다. 용량 압축과 변환은 제가 처리합니다.
5. 다 넣었다고 알려주시면 사이트에 연결합니다.

플로우덱(#2)은 제품 화면을 코드로 그리기 때문에 이미지가 필요 없습니다.
