# 2차 시안 이미지 — GPT 복붙용 프롬프트

## 사용 방법
1. 사이트별 **코드 블록 하나를 통째로 복사**해 GPT(이미지 생성)에 붙여넣습니다.
2. 각 이미지를 **적힌 파일명 그대로** 저장합니다. 저장 위치는 코드 블록 첫 줄에 있습니다(폴더는 미리 만들어 두었습니다).
3. 확장자는 GPT가 주는 그대로(.png) 저장하면 됩니다. 압축·변환은 제가 합니다.
4. 다 넣고 알려주시면 사이트에 연결합니다. 이미지가 없어도 사이트는 먼저 만들어 두고, 나중에 교체합니다.

필요한 이미지: 총 42장 (보유 사진으로 채울 수 있는 부분은 이미 제외했습니다)
