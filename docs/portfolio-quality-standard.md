# 포트폴리오 시안 "실제 운영 사이트" 기준표

시안 사이트는 "예쁜 화면"이 아니라 **지금 문을 연 가게·회사의 사이트**처럼 보여야 합니다.
사이트를 새로 만들거나 고칠 때 아래를 모두 점검합니다. (가상 업체임은 `SampleBadge`와 푸터 문구로 밝힙니다.)

## 10가지 요건
1. **사람**: 대표·의료진·강사·코치·작가는 글자 동그라미가 아니라 **가상 인물 사진**(실존 인물을 닮지 않게). 어린이 얼굴은 절대 넣지 않음(손·뒷모습·소품)
2. **공간·제품·작업 사진**: 같은 사진을 돌려 쓰지 않고, 업종에 필요한 장면(입구·내부·작업·결과물)을 갖춤. 히어로 외 사진이 최소 6장
3. **후기·사례**: 가상 후기 3개 이상(이름은 가림 처리), 가능하면 전/후·수치 사례
4. **FAQ**: 업종에서 실제로 자주 묻는 질문 5개 이상
5. **오시는 길**: 주소·교통·주차·영업시간·연락처, 간단한 지도 도식(SVG)
6. **공지·소식**: 날짜가 있는 글 3개 이상(이벤트·휴무·새 소식), 상세 보기
7. **푸터**: 사업자·대표·등록번호(가상 표기), 이용약관·개인정보 처리방침 링크, SNS 자리
8. **핵심 전환 기능**: 업종의 목표 행동(예약·신청·구매·상담)이 한 번에 끝나는 흐름과 완료 화면
9. **대표 인터랙션 1개 + 작은 연출**: 업종의 성격을 살리는 장치(메인 사이트 효과를 그대로 복사하지 않음)
10. **마감**: 모바일(360~390px)·태블릿 확인, 키보드·'동작 줄이기' 대응, 제목·메타·OG 이미지, 콘솔 에러 0

## 업종별 예외
- **법률·의료**: 의뢰인·환자 후기는 광고 규정상 제한되므로 싣지 않고, 익명 가상 사례 + "결과를 보장하지 않습니다" 문구로 대체. 푸터에 광고 고지(광고책임자·등록 표기) 링크
- **진짜 일을 해 주는 장치**를 하나 둔다 (예: 법률 = 기한 계산기, 새봄영어 = 레벨 찾기). 계산·진단 결과에는 "참고용" 문구와 상담 예약 연결을 붙인다

## 점검 방법 주의
- 등장 애니메이션 점검은 `is-in`을 강제로 붙이지 말고 **실제로 스크롤**해서 `[data-reveal]`의 opacity가 모두 1인지 본다 (재렌더로 표시가 지워지는 버그를 놓치지 않기 위함)

## 사진 규칙 (Codex 이미지)
- 요청문은 사이트마다 `인물 / 공간 / 수업·제품 장면`으로 나누고, 한 요청에 3~7장
- 인물 사진은 40~50% 반신, 세로 1024x1536, 자연광·약한 보정(광고 느낌 금지)
- 원본은 `assets-src/sites/<id>/` 에 보관, 사이트에는 1600px 이하 WebP
- 사이트 `content.js` 의 `READY_IMAGES`·`PHOTOS`에 등록하고, 사진 출처 표기는 스톡 사진에만
