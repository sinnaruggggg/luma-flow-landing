# 홈페이지 개선 계획

작업 위치는 D:\www\mypages입니다. 기존 React·Vite와 관리자·템플릿·포트폴리오 경로를 유지합니다.

1. 시안 3의 에디토리얼 구조와 시안 5의 녹색을 결합합니다. 히어로에는 종이·사진·타이포가 천천히 정렬되는 모션을 넣습니다.
2. 조건검색을 독립 컴포넌트로 만듭니다. 패널의 임시 선택과 URL에 확정된 검색 조건을 구분합니다.
3. 12개 예시 사례를 별도 데이터로 관리하고 검색·유사 추천·상세 화면을 연결합니다.
4. 기존 진입점에서 홈페이지·프로젝트 경로만 새 화면으로 연결합니다. 나머지 경로와 기존 수정 내역은 보존합니다.
5. 데이터 테스트, lint, build, PC·모바일 화면, 키보드·포커스·뒤로가기·새로고침·푸터 CTA를 검증합니다.

임시 브랜드와 가상 사례는 공개 전 교체해야 합니다. 상담 안내는 정보를 수집하거나 성공 접수를 가장하지 않습니다.
